Project Documentation

Project Title

Automatic Street Light System Using 8051 Microcontroller.

Objective

To automatically control street lights based on surrounding light intensity using an LDR sensor and 8051 microcontroller.

Programming Language

Embedded C.

Microcontroller

AT89C51.

Software Tools

- Keil µVision
- Proteus Design Suite

Working Principle

The LDR senses surrounding light intensity. ADC0804 converts the analog signal into digital data. The 8051 microcontroller processes the data and controls the street light automatically.
