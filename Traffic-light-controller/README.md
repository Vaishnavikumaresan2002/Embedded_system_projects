Traffic Light Controller

Project Overview

A traffic light control system developed using Arduino UNO.

Hardware

- Arduino UNO
- Red LED
- Yellow LED
- Green LED
- 220 Ohm Resistors

Programming Language

Embedded C / Arduino C++

Software

Wokwi Simulator

Concepts Used

- GPIO
- Digital Input/Output
- Timers and Delays
- State Machine

Working Principle

The system automatically controls three traffic lights in a predefined sequence: Red, Green and Yellow.

Project Type

Software Simulation
